# Meliorism

자연휴양림 예약 / 전국 축제 일정 / 마라톤 대회 / 명상 / 독서, 다섯 가지 카테고리로 구성된 사이트입니다.

## 페이지 구성

- `index.html` — 홈 화면(표지). 배경에 산·소나무·캠핑(텐트+모닥불) SVG 장면과
  "자연, 야생 그리고 자유에 대한 동경" 문구, 5개 카테고리 진입 카드가 있습니다.
- `forest.html` — **자연휴양림 예약** (기존에 만들던 실시간 빈자리 조회 + 예약 알림 기능 전체)
- `festivals.html` — **전국 축제 일정** (오늘~6개월 뒤까지, 지역별 축제 + 예약 안내)
- `marathon.html` — **마라톤 대회** (공공데이터 스냅샷 기반 검색·필터·정렬)
- `meditation.html` — **명상** (준비 중 안내 페이지)
- `reading.html` — **독서** (준비 중 안내 페이지)

## 전국 축제 일정 (festivals.html) 동작 원리

한국관광공사 **TourAPI**(공공데이터포털 "한국관광공사_국문 관광정보 서비스_GW")의
`searchFestival2`로 오늘부터 6개월 뒤까지의 축제를 지역(법정동 시도코드, `lDongRegnCd`)별로 조회합니다.

- `api/festivals.js` — 목록 조회 (지역·월 필터, 날짜 범위는 서버에서 자동 계산).
  시작일~종료일이 300일 이상인 "1년 내내 상시 개최" 축제는 목록에서 제외합니다.
- `api/festival-detail.js` — 카드에서 "상세보기"를 눌렀을 때만 `detailIntro2`를 호출해
  장소·운영시간·요금·프로그램·예약 안내(`bookingplace`, 값이 있을 때만 표시)를 가져옵니다.
  (모든 카드에 자동 호출하지 않는 이유: TourAPI 개발계정은 기능별 일일 트래픽 1,000건 한도가 있습니다.)
- 필요한 환경변수: `TOUR_API_KEY` (공공데이터포털에서 발급받은 인증키, URL 인코딩 전 원문)

## 마라톤 대회 (marathon.html) 동작 원리

대회명·일시·장소·종목·주최·신청기간·신청 홈페이지 URL 필드를 `marathon.js`의
`RACE_DATA`에 **정적 스냅샷(2026-09-07 기준, 예정 대회만 수록)**으로 담아두고,
프런트엔드에서 검색어·종목·정렬만 클라이언트 사이드로 처리합니다. 카드마다
"신청 홈페이지" 버튼을 달아 대회 공식 홈페이지(또는 신청 안내 페이지)로 바로
이동할 수 있고, 신청기간이 아직 공지되지 않은 대회는 "추후 공지"로 표시합니다.

- 문화체육관광부 **"국내마라톤대회 정보"**(공공데이터포털, `api.odcloud.kr`) 오픈API는
  인증키가 필요해 브라우저 코드에 그대로 넣으면 그대로 노출되기 때문에, 서버(API 라우트)
  없이 정적 데이터로 우회했습니다. 실시간 연동이 필요해지면 `api/festivals.js`처럼
  서버에서 인증키를 숨기고 대신 호출하는 라우트를 추가하면 됩니다.
- 공공데이터포털에는 아직 2026년 이후 대회가 등록되어 있지 않아, `RACE_DATA`는
  마라톤 정보 사이트·대회 공식 홈페이지를 교차 확인해 수동으로 채운 것입니다
  (접수 일정은 주최 측 사정으로 바뀔 수 있어, 참가 전 공식 홈페이지 재확인 필요).
  국내 마라톤은 보통 개최 6~9개월 전에야 날짜가 확정돼서, 2027년 4~5월 대회는
  확인 시점(2026-09-07) 기준 공식 발표된 게 없어 목록에 포함하지 못했습니다.
- 지난 대회는 목록에 남겨두지 않으므로, 날짜가 지나면 `RACE_DATA`에서 해당 항목을
  수동으로 지워야 합니다. 새 대회가 확정되면 배열에 추가하면 됩니다.

## 자연휴양림 예약 (forest.html) 동작 원리

산림청 통합예약 플랫폼 **숲나들e**(https://www.foresttrip.go.kr) 의 일반예약 검색 화면이
내부적으로 호출하는 비공식 AJAX 엔드포인트를 서버(Vercel Serverless Function, `api/search.js`)에서
대신 호출하고, 결과 HTML을 파싱해 JSON으로 프런트엔드에 내려줍니다.

- 프런트엔드: `forest.html` + `script.js` (정적 파일, 프레임워크 없음)
- 백엔드: `api/search.js` (Node.js, Vercel Serverless Function)

## 중요한 제약사항

- **공식 API가 아닙니다.** 숲나들e가 페이지 구조·엔드포인트를 바꾸면 언제든 동작하지 않을 수 있습니다.
- 현재는 **시설(휴양림) 단위의 예약가능/예약불가 + 잔여 건수**까지만 보여줍니다.
  개별 객실/야영 사이트 단위 상세 현황은 숲나들e의 NetFunnel 대기열을 통과해야 해서 포함하지 않았습니다.
- 실제 예약은 반드시 [숲나들e](https://www.foresttrip.go.kr)에서 진행해야 합니다. 이 도구는 조회 전용입니다.
- 과도한 자동 새로고침/크롤링은 상대 서버에 부담을 줄 수 있으니 자제해 주세요. (`Cache-Control`로 2분 캐시 적용됨)

## 예약 알림(구글 캘린더) 기능

구글로 로그인하면, 관심 있는 휴양림 카드에서 "🔔 예약 알림 등록"을 눌러
예약이 열리는 요일/시간(또는 특정 날짜)을 직접 입력해 구글 캘린더에 일정으로 등록할 수 있습니다.

- 휴양림마다 예약 오픈 규칙이 제각각이고, 이를 웹사이트에서 100% 신뢰성 있게
  자동으로 알아내는 방법이 없어서(공지사항 게시판만 있고 정형 데이터가 없음),
  **규칙은 사용자가 직접 입력**합니다. (예: "매주 수요일 09:00")
- 입력을 돕기 위해 "🔔 예약 알림 등록" 패널을 열면 해당 휴양림의 **"선착순 예약정책" 공식 안내 원문**
  (`api/notice.js` → `selectRsrvtGdncView.do?...&menuId=004001001&ruleId=101`)을 자동으로 가져와 보여줍니다.
  이 URL 조합(menuId/ruleId)은 시설마다 동일하고 hmpgId만 다르다는 걸 확인해서, 신뢰도 높게 가져올 수 있습니다.
  (다만 일부 휴양림은 이 정책 자체가 없을 수 있어, 그런 경우 안내 문구를 대신 보여줍니다.)
- 필요한 환경변수: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`, `SESSION_SECRET`
  (Vercel 프로젝트의 Environment Variables에 설정되어 있어야 합니다.)
- 로그인 세션은 서버 DB 없이, 서명된 HttpOnly 쿠키에 저장됩니다.
